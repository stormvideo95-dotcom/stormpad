# StormPad 🎮
Mac menu-bar app that turns your game controller into a real keyboard — in every app and game.

1. Download `StormPad.zip` from Releases, unzip, drag **StormPad** to Applications.
2. Right-click → Open (first time only).
3. Allow **Accessibility** for StormPad in System Settings.
4. Open setup from the 🎮 menu-bar icon → **+ Add mapping** → press a controller button → press a key.
